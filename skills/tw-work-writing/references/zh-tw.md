# 台灣用語與編輯案例

讀者能一眼看懂、資訊又準確時就可以停手。用語依台灣的慣用法，並保留作者或品牌已指定的用詞。

## 用語看它指什麼

| 遇到的文字 | 可以怎麼處理 | 什麼時候保留 |
| --- | --- | --- |
| 視頻、軟件、郵箱 | 一般說明可寫「影片」「軟體」「電子郵件信箱」 | 逐字引文、正式名稱、實際介面標籤 |
| 支持 | 功能相容性可寫「支援」 | 表明立場或提供支持時，按原意保留 |
| 質量、數據 | 商品用「品質」，資訊可依意思寫「資料」或「數字」 | 物理的「質量」、既定指標名稱、自然的「數據分析」 |
| 優化、平台、流程 | 若指明確的工作或系統，可以直接用 | 「將全面優化使用者體驗」若沒有內容可核對，依正文資訊縮短或標出缺項 |
| 退款、退貨、退刷、入帳 | 沿用政策或實際狀態的叫法 | 各詞可能指不同動作或階段，勿為避免重複而輪替 |
| 您、你、貴公司 | 依對象、管道和品牌規範選用 | 已定調的客服稿沿用原稱謂，文中保持一致 |

中文行文使用中文標點。中英混合時保護網址、識別碼、產品名、按鈕名和原始引文。日期格式及貨幣寫法可依指定版型調整，必須保留原來的日期、幣別、精確度和單位。

## 常見的編輯判斷

| 問題 | 修改方式 |
| --- | --- |
| 「接下來將針對整體情況做完整的說明。」 | 若下一句已交代進度，直接從進度開始。需要走好幾步才能完成時，保留有用的導引。 |
| 「針對出貨時間進行查詢。」 | 可收成「查詢出貨時間」。先確認誰會查、已經查了或僅能查，再決定怎麼寫主詞與時態。 |
| 「彰顯團隊持續改善的決心。」 | 若前文有具體行動，留行動即可。涉及作者有意表達的主張時，保留原有歸屬。 |
| 每段用不同名字稱呼同一張訂單 | 用同一個名稱一路寫下去。客戶不必先分辨「案件」「需求」「該筆事項」是不是同一件事。 |
| 每個客服問題都以「我們完全理解您此刻的感受」開場 | 據實回應。有明確延誤時可以說「讓您多等了兩天，很抱歉」。先確認真的多等了兩天，或直接回答已知狀態。 |
| 三個條件整齊列出，或報告出現「然而」 | 真有三個條件時可留清單。轉折影響意思時保留「然而」或等義連接。 |
